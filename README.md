# Airline Passenger Satisfaction Prediction

A project for Kaggle Playground Series – Season 6, Episode 10.

The goal is to predict whether an airline passenger is satisfied. I used LightGBM and created features from passenger ratings, delays, and flight distance.

## Result

Kaggle public leaderboard ROC-AUC: **0.96031**  
Score recorded on October 25, 2026. The final ranking may differ.

## What I learned

- Preparing data for a machine learning model
- Creating useful features
- Evaluating predictions with ROC-AUC
- Improving a model through experiments

I developed this project with AI assistance as part of my learning process.
